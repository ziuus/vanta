Dashboard modes

Six views, one keystroke apart

Press 1–6 to switch. Every mode is a full-pane layout — no overlapping windows, no mouse.

1OverviewFull monitoring grid — CPU per‑core (usage, temp, freq), memory & swap, disk I/O with sparklines, network throughput, GPU utilization & VRAM, clock with battery, MPRIS media player, calendar, music visualizer, system info, live process table.
2MonitorFocused system metrics — CPU, memory, disk, network, GPU, and machine info in a compact layout. Ideal for glance‑and‑go health checks.
3ProcessesFull‑width live process table with sort, search, tree view, scroll, kill, and detail view. Every action has a key.
4MediaLarge music visualizer, MPRIS player controls, and a prominent clock in one immersive pane. Space play/pause, n next.
5AestheticClock, calendar, music visualizer, and matrix‑rain animation. Pure terminal eye candy.
6SettingsCurrent theme display, mode switching help, config file path, and full keyboard reference. Theme changes persist to ~/.config/vanta/config.toml.

Real‑time monitoring

Every metric,
live in your terminal

CPU per‑core utilisation with temperature and frequency, memory and swap, disk usage and I/O, network throughput with sparklines, GPU utilisation and VRAM — all updated at your configured refresh rate.

  • sysinfo backend — no external dependencies beyond Rust
  • NVIDIA GPU support via nvml (optional)
  • Configurable refresh rate in ~/.config/vanta/config.toml

Process explorer

Find, sort, kill
without leaving the TUI

A full‑width live process table with keyboard‑driven controls. Search by name, sort by any column, toggle tree view, inspect details, and kill processes — all without a mouse.

  • / search, s cycle sort, t tree view
  • k kill selected process, i detail pane
  • PID, user, CPU%, mem%, RSS, state, command — sortable

Get started

Install in two commands

Rust nightly required. Clone, build, and run.

Quick install

cargo install --git https://github.com/ziuus/vanta

From source

git clone https://github.com/ziuus/vanta
cd vanta
cargo run --release

Demo mode (no hardware needed)

cargo run -- --demo

Generates fake data so you can explore every mode and widget without live hardware. Perfect for screenshots and evaluation.

Configuration

~/.config/vanta/config.toml

Enable or disable individual widgets, set the refresh rate, and choose your default theme. Changes take effect on next launch.

[ui]
refresh_rate = 0.5
theme = "dark"

[widgets]
cpu = true
memory = true
disk = true
network = true
gpu = true
clock = true
calendar = true
music_viz = true
processes = true
media = true
